Playwright Codegen: Record and Playback

Stuck on a selector? Let Playwright write the code for you. The generic Record & Playback tool actually produces clean, usable code.

How to use?

Run the following command in your terminal:

npx playwright codegen wordpress.com

Two windows will open:

  1. A browser window where you interact with the site.
  2. A Playwright Inspector window that records your actions as code.

Emulation

You can even record scripts for mobile viewports:

npx playwright codegen --device="iPhone 12"
