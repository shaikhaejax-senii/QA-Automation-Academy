Playwright Selectors & Locators

Playwright introduces a user-centric way of finding elements. Instead of "Find the div with class 'btn'", you tell it: "Find the button with text 'Submit'".

Best Practices

Playwright recommends avoiding XPath/CSS selectors tied to structure. Instead, use locators that resemble how a user interacts with the page.

getByRole (Recommended)

Locates by ARIA role, ARIA attributes and accessible name.

await page.getByRole('button', { name: 'Submit' }).click();
await page.getByRole('heading', { name: 'Welcome' }).isVisible();

getByText

Finds an element by its text content.

await page.getByText('Success!').isVisible();

getByLabel

Great for finding form fields associated with a label.

await page.getByLabel('Password').fill('secret');
