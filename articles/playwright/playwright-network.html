Network Interception & Mocking

Playwright allows you to monitor and modify network traffic. This is useful for testing edge cases like server errors.

Mocking APIs

test('mocks api response', async ({ page }) => {
  await page.route('**/api/users', route => {
    route.fulfill({
      status: 200,
      contentType: 'application/json',
      body: JSON.stringify([{ id: 1, name: 'Mocked User' }]),
    });
  });

  await page.goto('https://example.com');
});

Aborting Requests

Block images or heavy scripts to speed up tests.

await page.route('**/*.{png,jpg,jpeg}', route => route.abort());
