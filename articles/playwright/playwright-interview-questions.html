Top 20 Playwright Interview Questions

Ace your next interview with these specific Playwright concepts that separate it from Selenium.

1. What makes Playwright different from Selenium?

Playwright uses WebSocket connection (DevTools protocol) for direct communication, while Selenium uses HTTP Driver API. Playwright is faster and has auto-waiting.

2. What is Browser Context?

A Browser Context is an isolated incognito-alike session. It is cheap to create. Tests in Playwright run in new contexts, not new browsers, making them super fast.

3. How does Playwright handle Shadow DOM?

It pierces Shadow DOM automatically. You don't need any special commands, standard locators just work inside shadow roots.

4. What is Trace Viewer?

A GUI tool to inspect test execution. It captures screenshots, DOM snapshots, network requests, and console logs for every action (Time Travel Debugging).

5. Can Playwright handle Multi-tab scenarios?

Yes, using `Page` events. `const [newPage] = await Promise.all([context.waitForEvent('page'), link.click()])`.
