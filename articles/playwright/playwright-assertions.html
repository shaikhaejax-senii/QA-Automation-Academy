Assertions and Auto-waiting

In Selenium, you often need `WebDriverWait` before asserting. In Playwright, assertions retry automatically until they pass or timeout.

Auto-waiting

When you use `expect(locator).toHaveText("Submit")`, Playwright checks if the element has the text "Submit". If it initially says "Loading...", Playwright waits and retries until it changes to "Submit".

Common Assertions

import { expect } from '@playwright/test';

// Check visibility
await expect(page.getByRole('button')).toBeVisible();

// Check text
await expect(page.locator('.alert')).toHaveText('Success');

// Check URL
await expect(page).toHaveURL(/.*checkout/);

// Check Value
await expect(page.locator('#name')).toHaveValue('Alice');

Soft Assertions

By default, if an assertion fails, the test stops. Soft assertions allow the test to continue and report failures at the end.

await expect.soft(page.getByText('Error')).toBeHidden();
// Test continues even if 'Error' is visible
