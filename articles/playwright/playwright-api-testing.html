API Testing with Playwright

You don't need RestAssured if you are using Playwright. It has a powerful built-in `request` fixture.

Why use Playwright for API?

  • Unified tech stack (TypeScript/JavaScript).
  • Share authentication state between UI and API tests.
  • Fast and lightweight.

GET and POST Example

test('API GET Request', async ({ request }) => {
    const response = await request.get('https://reqres.in/api/users/2');
    expect(response.ok()).toBeTruthy();
    const json = await response.json();
    expect(json.data.first_name).toBe('Janet');
});

test('API POST Request', async ({ request }) => {
    const response = await request.post('https://reqres.in/api/users', {
        data: {
            name: 'morpheus',
            job: 'leader'
        }
    });
    expect(response.status()).toBe(201);
});
