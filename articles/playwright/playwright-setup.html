Playwright Setup with TypeScript

Playwright has shaken up the automation world. It's fast, reliable and handles modern web constructs (like shadow DOM and frames) out of the box.

Prerequisites

  • Node.js: Make sure you have Node.js 14+ installed.
  • Code Editor: VS Code is highly recommended for its Playwright extension.

Installation

Run the init command. This will scaffold a new project and download the browsers. 

npm init playwright@latest

You'll be asked a few questions:

  • TypeScript or JavaScript? -> TypeScript
  • Folder for tests? -> tests
  • Add a GitHub Actions workflow? -> Yes/No
  • Install Playwright browsers? -> Yes

Your First Test

Create a file `tests/example.spec.ts`: 

import { test, expect } from '@playwright/test';

test('has title', async ({ page }) => {
  await page.goto('https://playwright.dev/');

  // Expect a title "to contain" a substring.
  await expect(page).toHaveTitle(/Playwright/);
});

Run the test: 

npx playwright test
