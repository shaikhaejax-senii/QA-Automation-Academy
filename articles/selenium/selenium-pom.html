Page Object Model (POM) Design Pattern

POM is the gold standard for test automation. It separates the Test Logic (Assertions) from the Page Details (Locators).

What is POM?

In POM, every webpage in your application is a Class. The elements on that page are Variables, and the interactions are Methods.

Benefit: If the Login ID changes from "id=user" to "id=username", you change it in one place (LoginPage.java), not in 50 test scripts.

Page Factory

A Selenium support class to initialize elements lazily.

Implementation without Page Factory (Preferred)

Modern frameworks often skip PageFactory to avoid `StaleElementReferenceException` and use simple By locators. 

public class LoginPage {
    private WebDriver driver;
    
    // Locators (Encapsulation)
    private By username = By.id("user");
    private By password = By.id("pass");
    private By loginBtn = By.id("btn");

    public LoginPage(WebDriver driver) {
        this.driver = driver;
    }

    // Action Method
    public void doLogin(String u, String p) {
        driver.findElement(username).sendKeys(u);
        driver.findElement(password).sendKeys(p);
        driver.findElement(loginBtn).click();
    }
}
