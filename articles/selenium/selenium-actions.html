Advanced Interactions with Actions Class

Sometimes `click()` isn't enough. For menus that open on hover, drag-and-drop interfaces, or double clicks, we need the Actions class.

Mouse Hover

Actions act = new Actions(driver);
WebElement menu = driver.findElement(By.id("menu"));

act.moveToElement(menu).perform(); // Hover

Drag and Drop

WebElement src = driver.findElement(By.id("source"));
WebElement tgt = driver.findElement(By.id("target"));

act.dragAndDrop(src, tgt).perform();

Keyboard Events

Sending special keys like SHIFT, CTRL, etc.

act.keyDown(Keys.SHIFT)
   .sendKeys("hello")
   .keyUp(Keys.SHIFT)
   .perform(); // Types "HELLO"

Common Mistakes

  • Forgetting `.perform()` at the end. The action won't run without it!
