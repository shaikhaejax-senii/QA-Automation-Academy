Building Frameworks with TestNG

Selenium allows you to drive the browser, but TestNG allows you to manage the tests. It provides reporting, assertions, and parallel execution.

Key Annotations

  • `@Test`: Marks a method as a test case.
  • `@BeforeMethod`: Runs before every test (e.g., launch browser).
  • `@AfterMethod`: Runs after every test (e.g., close browser).
  • `@BeforeTest`: Runs once before the `` tag in xml.

Assertions

Verification points. Without assertions, your test is useless.

Assert.assertEquals(driver.getTitle(), "Google");
Assert.assertTrue(btn.isDisplayed());

Data Provider

Running the same test with different data (Data Driven Testing).

@DataProvider(name = "loginData")
public Object[][] getData() {
    return new Object[][] {
        {"admin", "pass123"},
        {"user", "user123"}
    };
}

@Test(dataProvider = "loginData")
public void loginTest(String username, String password) {
    // Test logic comes here
}
