Common WebDriver Commands

Your daily toolkit for interacting with web pages.

Browser Commands

  • `driver.get(url)`: Opens a URL.
  • `driver.getCurrentUrl()`: Gets current URL (for validation).
  • `driver.close()`: Closes current window.
  • `driver.quit()`: Closes all windows and kills session.

Element Commands

WebElement btn = driver.findElement(By.id("submit"));

btn.click(); // Click
btn.sendKeys("Text"); // Type
btn.clear(); // Clear text
String text = btn.getText(); // Get visible text
String attr = btn.getAttribute("class"); // Get HTML attribute

Validation Commands

Verification is key in testing.

  • `isDisplayed()`: Checks if element is visible.
  • `isEnabled()`: Checks if element is interactive.
  • `isSelected()`: Checks if checkbox/radio is selected.
