Top 20 Selenium Interview Questions

The definitive list of Selenium questions for 2026. From basic commands to advanced framework design.

1. Difference between findElement and findElements?

`findElement` returns the first matching element or throws exception if not found.
`findElements` returns a List of WebElements. Returns empty list if not found (no exception).

2. How to handle dynamic web elements?

Use dynamic XPath axes like `following-sibling`, `parent`, `ancestor` or `contains()`, `starts-with()`.

3. What is StaleElementReferenceException?

It occurs when the element is no longer attached to the DOM (page refreshed or changed). Fix: Re-initialize the element or use Page Factory.

4. How to handle multiple windows/tabs?

Using `driver.getWindowHandles()`. Iterate through the Set of handles and use `driver.switchTo().window(handle)`.

5. Why do we prefer CSS Selectors over XPath?

CSS Selectors are generally faster and have simpler syntax. However, XPath is needed for traversing up the DOM (parent/ancestor).
