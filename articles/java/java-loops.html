Loops and Control Flow

Automation scripts are logic-heavy. You need to iterate through tables, check if elements exist, and repeat actions until a condition is met.

If-Else Conditions

Used for decision making. E.g., taking a screenshot only if the test fails.

For Loops

Used when you know exactly how many times you want to iterate.

// Iterate through 5 rows of a table
for(int i = 1; i <= 5; i++) {
    System.out.println("Reading Row " + i);
}

Enhanced For Loop (For-Each)

The preferred way to iterate over Collections (Lists, Sets) in automation.

List links = driver.findElements(By.tagName("a"));

for(WebElement link : links) {
    System.out.println(link.getText());
}

While & Do-While

Used when the number of iterations is unknown. Example: Waiting for a file to finish downloading.
