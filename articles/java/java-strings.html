String Manipulation in Java

In Automation, you constantly read text from web elements and verify it. Java String methods are your primary tool for validation.

Common Methods

1. equals() vs ==

`equals()` compares content, `==` compares memory reference. Always use `equals()` for strings.

2. split()

Used to break a string into an array based on a delimiter.

String msg = "Welcome to Selenium";
String[] words = msg.split(" ");
// words[0] -> "Welcome"

3. substring()

Extracting a part of the text.

String price = "Total: $500";
String amount = price.substring(8); // Outputs "500"

StringBuilder

Strings are immutable in Java. Every time you modify a string, a new object is created. If you have many modifications (like in a loop), use `StringBuilder` for performance.

Interview Questions

  • Q: Why is String immutable?
    For security, synchronization, and caching (String Pool).
  • Q: Difference between String, StringBuilder, and StringBuffer?
    String is immutable. StringBuilder is mutable (fast, not thread-safe). StringBuffer is mutable and thread-safe (slow).
