Java Collections Framework

Handling groups of objects is central to testing. Whether it's a list of dropdown options, a set of window handles, or a map of test data, Collections are everywhere.

Hierarchy

The root interface is `Collection`. However, in automation, we mostly care about 3 main interfaces:

  • List: Ordered, allows duplicates.
  • Set: Unordered, unique elements only.
  • Map: Key-Value pairs (Note: Does not extend Collection interface).

List Interface

ArrayList is the most used implementation. It's dynamic, fast for reading.

Automation Use Case: Storing a list of WebElements found by `driver.findElements(By.xpath("//a"))`.

List names = new ArrayList<>();
names.add("Alice");
names.add("Bob");
names.add("Alice"); // Duplicates allowed

// Iterating
for(String name : names) {
    System.out.println(name);
}

Set Interface

HashSet is the most common. It stores unique values.

Automation Use Case: Handling Window Handles. Selenium returns window handles as a Set because each window ID must be unique.

Set handles = driver.getWindowHandles();

for(String handle : handles) {
    driver.switchTo().window(handle);
}

Map Interface

HashMap stores data in Key-Value pairs.

Automation Use Case: Storing Test Data (e.g., loaded from Excel or JSON) where column header is Key and cell value is Value.

Map userData = new HashMap<>();
userData.put("username", "admin");
userData.put("password", "12345");

System.out.println(userData.get("username"));

Interview Questions

  • Q: Difference between Array and ArrayList?
    Array is fixed size, ArrayList is dynamic.
  • Q: Difference between HashMap and HashTable?
    HashMap is non-synchronized and allows null keys/values. HashTable is synchronized (slow) and doesn't allow nulls.
  • Q: How to remove duplicates from a List?
    Convert it to a HashSet: `Set<String> s = new HashSet<>(myList);`
