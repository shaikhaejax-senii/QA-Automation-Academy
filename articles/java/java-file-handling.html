File Handling for Test Automation

Automation frameworks rely heavily on external files for configuration (URL, browser type) and test data (Excel sheets). Java provides robust IO capabilities.

Reading Properties Files

Config files (`config.properties`) are the standard way to store Key-Value pairs like environment URLs. 

Properties prop = new Properties();
FileInputStream fis = new FileInputStream("config.properties");
prop.load(fis);

String url = prop.getProperty("baseUrl");
System.out.println(url);

Reading Text/CSV

Using `BufferedReader` is efficient for reading large log files or simple CSV data.

BufferedReader br = new BufferedReader(new FileReader("data.csv"));
String line;
while ((line = br.readLine()) != null) {
    System.out.println(line); // Prints each row
}
br.close();

Excel Interaction

Java does not support Excel natively. We use the Apache POI library.

Common Mistakes: Forgetting to close the workbook, resulting in memory leaks.

Note: Apache POI requires adding dependencies to your `pom.xml`.
