Java Basics: Setup and Syntax

Before we dive into Selenium or RestAssured, we need a solid foundation in Java. This guide covers setting up your environment and writing your first program.

Environment Setup

You'll need two things:

  • JDK (Java Development Kit): The compiler and runtime environment.
  • IDE (Integrated Development Environment): We recommend IntelliJ IDEA Community Edition.

Hello World

Every programming journey starts here. Create a new file named Main.java. 

public class Main {
    public static void main(String[] args) {
        // This prints to the console
        System.out.println("Hello, QA Automation!");
    }
}

Variables & Data Types

Java is statically typed, meaning you must declare the type of a variable. 

int age = 25;
double salary = 65000.50;
boolean isAutomated = true;
String role = "QA Engineer";

System.out.println(role + " with age " + age);
