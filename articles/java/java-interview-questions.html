Top 20 Java Interview Questions for QA

Common Java interview questions asked to Automation Engineers, covering OOP concepts, Collections, and Logical programs.

1. What are the 4 pillars of OOPs?

Abstraction, Encapsulation, Inheritance, and Polymorphism.

2. Why is String immutable in Java?

Because of the String Constant Pool. If one reference changes the value, it would affect other references. It provides security, caching, and thread-safety.

3. Difference between method Overloading and Overriding?

Overloading: Same method name, different parameters (Compile-time polymorphism).
Overriding: Same method name and parameters in parent and child class (Runtime polymorphism).

4. Difference between Interface and Abstract Class?

Interface supports multiple inheritance and has only abstract methods (pre-Java 8). Abstract class can extend only one class and can have both abstract and concrete methods.

5. Why do we use Static keywords in Automation?

Ideally, we should minimize it to allow parallel execution. However, we use `static` for utility helper methods that don't depend on instance state (e.g., `DateUtils.getCurrentDate()`).
