Getting Started with UFT One

Unified Functional Testing (formerly QTP) is Micro Focus's flagship automation tool. It is famous for its Object Repository and support for non-web apps (Desktop, SAP, Mainframe).

What is UFT?

UFT One uses VBScript as its scripting language. Unlike Selenium, UFT provides a full IDE with built-in features for Object identification (Spy), Data Tables (Excel-like), and Reporting.

Add-in Manager

When you start UFT, the first thing you see is the Add-in Manager. Select only the add-ins you need (e.g., Web, WPF, Java) to keep UFT running fast.

Record & Playback

UFT's recording capability is very strong.

  1. Click Record.
  2. Perform actions on your application (Flight Reservation App is the classic sample).
  3. Stop recording.
  4. UFT generates VBScript automatically.
Window("Flight Reservation").WinEdit("Name").Set "John Doe"
