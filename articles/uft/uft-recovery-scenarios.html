Recovery Scenario Manager

Exceptions happen. A popup might appear, or the application might crash. Recovery Scenarios allow the test to continue instead of halting execution.

Triggers

UFT can detect the following events:

  • Popup Window: An unexpected dialog box.
  • Object State: An object is disabled or missing.
  • Test Run Error: Any VBScript runtime error.
  • Application Crash: The app process terminates.

Recovery Operations

Once triggered, UFT can perform:

  • Keyboard/Mouse click (e.g., press ESC or click Close).
  • Close Application process.
  • Function Call (Call a custom VBScript function to handle complex logic).
  • Restart Microsoft Windows.

On Error Resume Next

For purely script-level error handling, you can use the VBScript statement: 

On Error Resume Next
' Risky code
x = 1 / 0
If Err.Number <> 0 Then
    Print "Error Occurred: " & Err.Description
    Err.Clear
End If
On Error GoTo 0
