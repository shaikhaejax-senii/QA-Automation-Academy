Top 20 UFT (QTP) Interview Questions

Questions covering Logic, Object Identification, and Frameworks.

1. What is the difference between Shared and Local Object Repository?

Local is saved within the action files and accessible only to that action. Shared is saved as a `.tsr` file and can be accessed by multiple tests/actions.

2. What is Descriptive Programming?

Technique to identify objects directly using property-value pairs in the script without storing them in the Object Repository.

3. What is Smart Identification?

When UFT cannot find an object using mandatory and assistive properties, it uses Smart Identification (if enabled) to find the most likely candidate based on fuzzy matching logic. It makes tests slower, so often disabled.

4. How to call a function from an external library?

Save the function in a `.qfl` or `.vbs` file. Associate it via `File > Settings > Resources`. Then call the function name directly in the script.

5. What are Ordinal Identifiers?

Used when multiple objects matches the properties. Types: Index (based on appearance order), Location (x,y), CreationTime (for Browsers).
