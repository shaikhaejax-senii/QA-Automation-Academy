Descriptive Programming (DP)

Descriptive Programming allows you to run tests for objects that are not in the Object Repository. You provide the property-value pairs directly in the script.

Why use DP?

  • Dynamic objects that change properties at runtime.
  • Handling similar objects (e.g., 50 checkboxes) using loops.
  • Framework portability (no dependency on .tsr files).

Type 1: Inline (Static Binding)

Format: `("Property1:=Value1", "Property2:=Value2")` 

Browser("name:=Google").Page("title:=Google").WebEdit("name:=q").Set "UFT"

Type 2: Description Object (Dynamic Binding)

Create a `Description` object and add properties to it. Useful for ChildObjects. 

Set oDesc = Description.Create()
oDesc("micclass").Value = "WebCheckBox"

Set colLinks = Browser("B").Page("P").ChildObjects(oDesc)
MsgBox "Total Checkboxes: " & colLinks.Count
