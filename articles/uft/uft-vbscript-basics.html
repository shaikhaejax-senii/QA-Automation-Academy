VBScript Essential Guide

UFT relies heavily on VBScript. It's case-insensitive and loosely typed.

Variables

Always use `Option Explicit` at the top of your script to force variable declaration. Use `Dim` to declare.

Option Explicit
Dim strName, intAge
strName = "UFT User"
intAge = 10
MsgBox "Hello " & strName

Control Structures

' If-Else
If intAge > 18 Then
    MsgBox "Adult"
Else
    MsgBox "Minor"
End If

' For Loop
Dim i
For i = 1 To 5
    Print i
Next

Subroutines vs Functions

`Sub` performs an action but returns no value.
`Function` performs an action and can return a value. 

Function AddNumbers(a, b)
    AddNumbers = a + b ' Return value assignment
End Function

MsgBox AddNumbers(5, 10)
