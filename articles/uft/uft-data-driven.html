Data Driven Testing with DataTable

Running the same test logic with different sets of data is the core of automation. UFT provides an integrated Excel-like sheet called DataTable.

Global vs Local Sheet

  • Global Sheet: Accessible to all actions. Controls the number of iterations for the entire test.
  • Local Sheet: Accessible only to the specific action. Controls iterations for that action only.

Parameterizing a Step

To utilize the data, replace the hardcorded value with `DataTable("ColumnName", dtGlobalSheet)`. 

' Old
Browser("B").Page("P").WebEdit("User").Set "admin"

' New (Parameterized)
Browser("B").Page("P").WebEdit("User").Set DataTable("Username", dtGlobalSheet)

Importing External Excel

You can import data at runtime. 

DataTable.ImportSheet "C:\Data\Test.xls", "SourceSheet", "Global"
