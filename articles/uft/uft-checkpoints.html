Checkpoints & Output Values

A "Checkpoint" is UFT's term for assertion. It verifies if Actual Result matches Expected Result.

Standard Checkpoint

Checks properties of an object (e.g., verify button "Submit" is enabled).
Insert > Checkpoint > Standard Checkpoint

Validation via VBScript (Reporter.ReportEvent)

Most pros prefer writing code over using recording options. 

If Browser("B").Page("P").WebButton("Submit").Exist(5) Then
    Reporter.ReportEvent micPass, "Submit Button", "Button exists."
Else
    Reporter.ReportEvent micFail, "Submit Button", "Button missing."
End If

Output Values

Capturing a value from the application (e.g., Order ID generated) and storing it in DataTable for later use.
