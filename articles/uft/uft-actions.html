Actions and Function Libraries

Modularizing your UFT test is essential for maintenance.

Understanding Actions

Every UFT test starts with "Action1". You can split this into multiple logical steps: "Login", "BookFlight", "Logout".

Reusable Actions

By determining an action as "Reusable", you can call it from other tests.
Insert > Call to Existing Action

Function Libraries (.qfl)

Actions are heavy. For pure logic (no object repository needed) or general utility functions (e.g., DateFormatter, MathCalc), use Function Libraries.

Associate them via `File > Settings > Resources`. 

' saved in Utils.qfl
Function Login(user, pass)
    Window("App").WinEdit("User").Set user
    Window("App").WinEdit("Pass").Set pass
    Window("App").WinButton("OK").Click
End Function
