Getting Started with TypeScript

TypeScript is a superset of JavaScript that adds static typing. It compiles down to plain JavaScript.

What is TypeScript?

JavaScript is loosely typed. TypeScript enforces types at compile time, reducing runtime errors.

Installation

First, install Node.js. Then install TypeScript globally: 

npm install -g typescript

Verify installation:

tsc --version

tsconfig.json

Every TypeScript project needs a configuration file. 

tsc --init

This creates `tsconfig.json` where you define compiler options like `target`, `module`, and `outDir`.
