Types and Interfaces

The core feature of TypeScript. Defining the shape of your data.

Basic Types

let isDone: boolean = false;
let lines: number = 42;
let name: string = "QA Academy";
let list: number[] = [1, 2, 3];
let notSure: any = 4; // Avoid 'any' when possible!

Interfaces

Interfaces define the contract for an object. 

interface User {
    id: number;
    username: string;
    isActive?: boolean; // Optional property
}

const u: User = { id: 1, username: "admin" };

Type Aliases vs Interfaces

They are similar, but Interfaces are extendable (open), whereas Types are not. Use Interfaces for Objects, and Types for Unions/Primitives. 

type Status = "Pending" | "Approved" | "Rejected";
let currentStatus: Status = "Approved";
