Functions & Arrow Functions

Functions are the building blocks of any application. TypeScript allows you to specify input and output types.

Typed Parameters

function add(x: number, y: number): number {
    return x + y;
}

Arrow Functions

A shorter syntax, commonly used in callbacks and modern frameworks. 

const multiply = (x: number, y: number): number => x * y;

Optional & Default Parameters

function greet(name: string, greeting: string = "Hello"): string {
    return `${greeting}, ${name}`;
}

function buildName(first: string, last?: string) {
    // last is optional
}
