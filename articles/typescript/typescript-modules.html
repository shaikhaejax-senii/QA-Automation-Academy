Modules (Import & Export)

In modern TypeScript/JavaScript, code is split into modules. Any file containing a top-level `import` or `export` is considered a module.

Exporting

// math.ts
export function add(x: number, y: number) {
    return x + y;
}

export const PI = 3.14159;

Importing

// app.ts
import { add, PI } from "./math";

console.log(add(10, 5));

Default Exports

Each module can have one `default` export. This is useful for exporting a single class or function. 

// Logger.ts
export default class Logger {
    log(msg: string) { console.log(msg); }
}

// app.ts
import Logger from "./Logger"; // No braces needed
